# Rettskilder

Et norsk lønnssystem berøres av minst 15 lover. Tabellen viser hvilke, og hva hver av dem krever av systemet. Forskrifter og årlige stortingsvedtak (satser) kommer i tillegg og omtales under hvert område.

| Lov | Regulerer for lønn | Hva systemet må gjøre |
| --- | --- | --- |
| [A-opplysningsloven](https://lovdata.no/lov/2012-06-22-43) med a-opplysningsforskriften | Månedlig rapportering av inntekt, arbeidsforhold, trekk og avgift | Lage og sende a-melding, håndtere tilbakemeldinger og korrigeringer |
| [Skattebetalingsloven](https://lovdata.no/lov/2005-06-17-67) med skattebetalingsforskriften | Forskuddstrekk, utleggstrekk, forfall og innbetaling (skattetrekkskonto avviklet fra 1.1.2026) | Beregne trekk etter skattekort og betale det inn første virkedag etter utbetaling |
| [Skatteloven](https://lovdata.no/lov/1999-03-26-14) | Hva som er skattepliktig fordel (§ 5-1, § 5-12), skattefrie ytelser | Klassifisere ytelser og naturalytelser riktig |
| [Skatteforvaltningsloven](https://lovdata.no/lov/2016-05-27-14) | Opplysningsplikt, endring, tilleggsskatt og tvangsmulkt | Støtte korrigering og dokumentasjon av innsendte data |
| [Folketrygdloven](https://lovdata.no/lov/1997-02-28-19) kap. 8, 9, 14, 23 | Sykepenger, omsorgspenger, foreldrepenger, arbeidsgiveravgift | Arbeidsgiverperiode, refusjon, AGA-beregning per sone |
| [Ferieloven](https://lovdata.no/lov/1988-04-29-21) | Feriepengeopptjening og utbetaling | Opptjene, avsette og utbetale feriepenger |
| [Arbeidsmiljøloven](https://lovdata.no/lov/2005-06-17-62) | Lønnsoppgave, trekk i lønn, overtid, arbeidsavtale | Lønnsslipp, lovlige trekk, overtidstillegg |
| [Allmenngjøringsloven](https://lovdata.no/lov/1993-06-04-58) | Minstelønn i allmenngjorte bransjer | Kontrollere minstesatser |
| [Likestillings- og diskrimineringsloven](https://lovdata.no/lov/2017-06-16-51) | Likelønn, lønnskartlegging | Kjønnsdelt lønnsstatistikk |
| [OTP-loven](https://lovdata.no/lov/2005-12-21-124) | Obligatorisk tjenestepensjon | Beregne pensjonsgrunnlag og innskudd |
| [Yrkesskadeforsikringsloven](https://lovdata.no/lov/1989-06-16-65) | Obligatorisk yrkesskadeforsikring | Registrere ordningen; ingen beregning |
| [Dekningsloven](https://lovdata.no/lov/1984-06-08-59), [innkrevingsloven](https://lovdata.no/dokument/NL/lov/2025-04-25-12) og [tvangsfullbyrdelsesloven](https://lovdata.no/lov/1992-06-26-86) | Utleggstrekk for private og offentlige krav | Gjennomføre trekkpålegg, livsoppholdsgrense |
| [Bokføringsloven](https://lovdata.no/lov/2004-11-19-73) med bokføringsforskriften | Dokumentasjon, spesifikasjon og oppbevaring | Lønnsbilag, sporbarhet, oppbevaring i 5 år |
| [Personopplysningsloven](https://lovdata.no/lov/2018-06-15-38) (GDPR) | Behandling av ansattes personopplysninger | Tilgangsstyring, sletting, logging |

Folketrygdens satser og arbeidsgiveravgiften fastsettes hvert år i Stortingets vedtak om avgifter til folketrygden. Skattesatser og trekktabeller følger av Stortingets skattevedtak. I tillegg gjelder [innskuddspensjonsloven](https://lovdata.no/dokument/NL/lov/2000-11-24-81), [lønnspliktloven ved permittering](https://lovdata.no/dokument/NL/lov/1988-05-06-22), [aksjeloven](https://lovdata.no/lov/1997-06-13-44) (lån til ansatte) og svalbardskatteloven.
