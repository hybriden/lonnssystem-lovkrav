## Mål

Et koderepo der enhver senere pakke kan starte uten å ta verktøyvalg: løsning med fem prosjekter og fem testprosjekter, sentral pakkestyring, advarsler som feil, en arkitekturtest som låser avhengighetsretningen, et React-skjelett med lint, CI som kjører porten, og `CLAUDE.md` med reglene fra arkitekturdokumentet. Dette er pakken som gjør at K1- og K2-økter kan jobbe uten å måtte tolke arkitekturen.

## Omfang

- `Lonnssystem.slnx` med `src/Lonn.Domain`, `src/Lonn.Parametre`, `src/Lonn.Infrastruktur`, `src/Lonn.Integrasjoner`, `src/Lonn.Api` og ett xUnit-prosjekt per prosjekt under `tests/`.
- `global.json` som låser SDK 10.0.4xx. `Directory.Build.props` med `Nullable`, `ImplicitUsings`, `TreatWarningsAsErrors`, `EnforceCodeStyleInBuild`, `AnalysisLevel=latest-recommended`. `Directory.Packages.props` for sentral versjonsstyring.
- Prosjektreferanser etter arkitekturen: `Domain → Parametre`, `Infrastruktur → Domain`, `Integrasjoner → Domain`, `Api → Infrastruktur, Integrasjoner`.
- `tests/Lonn.Domain.Tests/ArchitectureTests.cs`: domenet refererer bare BCL og `Lonn.Parametre`, og har ingen `double`/`float` i offentlig API.
- `src/Lonn.Api/Program.cs` med bare `/health`.
- `web/` fra Vite-malen `react-ts` med oxlint, `npm run lint` og `npm run build`.
- `docker-compose.yml` med PostgreSQL 16 for lokal utvikling.
- `.github/workflows/ci.yml`: `dotnet format --verify-no-changes`, `dotnet build`, `dotnet test`, `npm run lint`, `npm run build`.
- `CLAUDE.md`, `README.md`, `docs/adr/0001-stack.md`, `docs/invariants/README.md` og `docs/invariants/domain-layer.md`.
- `.gitattributes` med LF, `.editorconfig`, `.gitignore`.

## Utenfor omfang

- Verdityper for penger og datoer (AP-002).
- EF Core, Npgsql, migreringer og revisjonslogg (AP-005).
- Autentisering (AP-006), OpenAPI og generert klient (AP-007), ruting og designtokens i `web/` (AP-008).
- Testcontainers og Playwright legges inn av den første pakken som trenger dem (AP-005 og AP-008).

## Regler

- Bokføringsforskriften § 7-5: elektronisk regnskapsmateriale lagres i Norge, EØS, Storbritannia eller Sveits. Derfor PostgreSQL hos leverandør i EØS, ikke en skydatabase uten regionsgaranti. Dokumentert i ADR 0001.
- Alle prinsippene i `plan/01-arkitektur.md` er gjentatt som kortversjon i `CLAUDE.md` og pekt til `docs/invariants/`.

## Akseptansekriterier

1. `dotnet build` gir 0 advarsler og 0 feil på ren klon.
2. `dotnet test` kjører og arkitekturtestene er grønne.
3. `dotnet format --verify-no-changes` passerer.
4. `cd web && npm ci && npm run lint && npm run build` passerer.
5. Å legge til `<PackageReference Include="Newtonsoft.Json" />` i `Lonn.Domain` får `Domain_references_only_bcl_and_parametre` til å feile. (Verifisert manuelt ved opprettelse; ikke sjekket inn.)
6. CI-arbeidsflyten kjører de samme stegene som porten i `CLAUDE.md`.
7. Repoet [hybriden/lonnssystem](https://github.com/hybriden/lonnssystem) er privat og har `main` som standardgren.
