## Mål

Systemet kan rulles ut til Azure i Norge med sikker konfigurasjon: API og database i Container Apps og PostgreSQL Flexible Server (Norway East), nettsiden med CSP og HSTS, hemmeligheter i Key Vault, nøkkelrotasjon, varsling og testet gjenoppretting.

## Omfang

- Dockerfile for API-et (ikke rot, helsesjekk) og hosting av `web/dist` (Static Web Apps eller nginx-bilde) med CSP, HSTS, `frame-ancestors 'none'`, `nosniff` og `Referrer-Policy`.
- Infrastruktur som kode (Bicep) for Container Apps, Flexible Server med geo-kopi til Norway West, Key Vault, lagringskonto for `pg_dump` med uforanderlig lagring, Log Analytics.
- Konfigurasjon: `Sikkerhet:KjenteProxynett` for proxyens subnett, `Amelding:Hendelsesnokkel`, Maskinporten-nøkler fra Key Vault, `LONN_KREV_POSTGRES`.
- Nøkkelrotasjon: jobb som krypterer gamle rader på nytt når aktiv nøkkel byttes (M-08), med test på en tabell.
- Varslingsregel i Azure Monitor: `Driftsvarsler` (EventId 9040) og feilede nattjobber gir varsel til administrator innen ett minutt.
- Gjenopprettingstest: rutinen i `docs/sikkerhetskopi.md` kjørt én gang mot et tomt miljø, med utfylt protokollrad.
- Utrullingspipeline fra `main` til et testmiljø med migrering først (`Migrate.Dockerfile`), så API, så nettside; tilbakerulling beskrevet.

## Akseptansekriterier

1. `docker compose up` lokalt gir et kjørende system med migrert database, og `/health` svarer 200 uten innlogging.
2. Nettsiden svarer med CSP, HSTS, `X-Content-Type-Options` og `frame-ancestors 'none'` (test mot bildet).
3. Bicep-malene validerer (`az bicep build`) og beskriver bare norske regioner; en test over malene avviser andre regioner.
4. Et kall gjennom proxyen med `X-Forwarded-Proto: https` godtas bare fra nettene i `Sikkerhet:KjenteProxynett`, og ratebegrensningen teller per klient-IP (test).
5. Nøkkelrotasjonsjobben krypterer alle rader med gammel nøkkel på nytt og lar seg kjøre om igjen uten endring (idempotent), med test.
6. Varslingsregelen er dokumentert med spørring og terskel, og en testlogglinje med EventId 9040 utløser varsel innen ett minutt i testmiljøet (protokollført).
7. Gjenopprettingen er gjennomført én gang og protokollført i `docs/sikkerhetskopi.md`.

## Tester

Containertest av helsesjekk og sikkerhetshoder, maltest for regioner, API-test for proxy og ratebegrensning, jobbtest for rotasjon.
