## Mål

Pakken lager registeret over personer som får lønn: identitet (fødselsnummer, D-nummer eller midlertidig utenlandsk ID), navn, adresse, kontonummer, skattekommune, bostedsland og opptjeningsland, og de feltene lønnsdokumentasjonen krever per mottaker. Identiteten kan byttes (D-nummer til fødselsnummer) uten å miste historikk.

## Omfang

- `Ansatt`: `AnsattId` (UUID), ansattnummer per arbeidsgiver (brukes på sammenstillingsoppgaven), navn, fødselsdato, kjønn (for lønnskartlegging, AP-704), adresse, e-post, telefon, kontonummer (norsk med modulus 11, eller IBAN/BIC), skattekommune, bostedskommune per 1.11 året før (brukes når skattekort mangler), skattemessig bostedsland, statsborgerskap, dødsdato.
- `AnsattIdentitet` med type (fødselsnummer, D-nummer, utenlandsk ID med utstederland og type), verdi (kryptert, fra AP-005), gyldig fra og til, og flagg `brukesIAMelding`. Én aktiv identitet. Bytte lager ny rad og lukker den gamle; a-meldingen får beskjed om byttet (AP-403 bruker historikken).
- Varsel når aktiv identitet er utenlandsk ID eller D-nummer eldre enn en konfigurerbar tid, med teksten om at norsk ID må skaffes.
- Hoved- eller biarbeidsgiver-flagg per ansatt per arbeidsgiver (brukes av AP-202 og AP-402).
- Endepunkter: opprett, oppdater, hent (maskert), liste med søk på navn og ansattnummer (aldri på fullt fødselsnummer i URL; søk på fødselsnummer skjer med POST og logges), bytt identitet, avslutt (ved død eller feilregistrering).
- Validering: fødselsnummer og D-nummer med begge kontrollsifre, fødselsdato konsistent med nummeret, kontonummer modulus 11.
- Importformat (CSV) for ansatte ved oppstart hos ny arbeidsgiver, med forhåndsvisning og feilrapport per rad.

## Utenfor omfang

- Arbeidsforhold, stilling og permisjoner (AP-104).
- Skattekort (AP-402). Pakken lagrer bare hoved/bi-flagget.
- Arbeidsavtale (AP-107).
- Særregler for utenlandske arbeidstakere som A1 og PAYE (AP-603, AP-204). Pakken lagrer feltene de trenger.
- Brukerflate (AP-801).

## Regler

- Inntektsmottaker identifiseres med fødselsnummer eller D-nummer; ellers navn, fødselsdato, utenlandsk ID og utstederland (a-meldingen, `docs/02`). D-nummer krever ID-kontroll hos skattekontoret. Utenlandsk ID kan brukes midlertidig men må byttes.
- Lønnsdokumentasjonen krever per mottaker fødselsnummer, navn, skattekommune og tabellnummer eller trekkprosent; uten skattekort bostedskommune per 1.11 året før (bokføringsforskriften § 5-6).
- Fødselsnummer kan brukes fordi lønn krever sikker identifisering (personopplysningsloven § 12), men maskeres, står aldri i URL eller logg.
- Lønn utbetales til bankkonto (arbeidsmiljøloven § 14-15).
- Ansattnummer skal med på sammenstillingsoppgaven (skatteforvaltningsforskriften § 7-13-2).

- Fra AP-506 (17.10.2026): tabellene `omsorgsgrunnlag` og `omsorgsbarn` (fødselsdato og om NAV-vedtak finnes, aldri sykdom) ble laget midlertidig i AP-506 fordi ansattregisteret ikke har barn. AP-103 bør overta dem som del av ansattregisteret.

## Akseptansekriterier

1. Opprettelse med fødselsnummer `01019012345`-liknende testnummer fra Tenor lykkes; nummer med feil kontrollsiffer gir 400 med feltfeil.
2. D-nummer gjenkjennes (første siffer 4 til 7), og fødselsdato utledes med dag minus 40.
3. Bytte fra D-nummer til fødselsnummer lukker den gamle identiteten med `gyldigTil` og lager ny; begge finnes i historikken, og hash-indeksen hindrer at det nye nummeret allerede finnes hos samme arbeidsgiver.
4. Liste-endepunktet returnerer maskert identitet og aldri 11 siffer; søk på fullt nummer går via POST og gir én rad i tilgangsloggen med formål «identitetssøk».
5. Ansattnummer er unikt per arbeidsgiver, og to arbeidsgivere kan ha ansattnummer 1.
6. Kontonummer `12345678903` godtas (modulus 11) og `12345678904` avvises.
7. CSV-import med 3 gyldige og 1 ugyldig rad gir forhåndsvisning med feilen på rad 4 og ingen rader lagret før bekreftelse.
8. Alle endringer er i revisjonsloggen med før og etter, der identitetsfeltet vises maskert.
